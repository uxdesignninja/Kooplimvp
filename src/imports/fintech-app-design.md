GFIN

📌 Figma Make Prompt
Design a minimalist fintech mobile app UI inspired by Apple Inc. and Airbnb.
The experience must feel:
Spatial. Calm. Intelligent. Premium. Minimal.
The app is built for overseas workers (including Filipino workers abroad and global migrant workers of any race) to manage money, build credit, and reach financial goals securely.

🌿 FIRST-TIME USER ONBOARDING FLOW
Design a smooth, emotionally intelligent onboarding experience.

1️⃣ Welcome Screen
Minimal layout.
* Soft neutral background
* Large centered headline: “Your money. Anywhere. Secure.”
* Subtext: “Built for global workers supporting home.”
* Primary button: Get Started
* Secondary: Log In
Subtle fade-in animation.

2️⃣ Value Proposition Carousel (3 Screens)
Horizontal swipe with minimal illustrations.
Screen 1 – Smart Wallet
Headline: “Send and manage money effortlessly.”
Short supporting text.

Screen 2 – Goals & Group Savings
Headline: “Save alone or together.”
Subtext explaining shared goal tracking.

Screen 3 – Credit & AI Support
Headline: “Build credit. Get smarter with AI.”
Small preview card of credit score + AI suggestion.
Pagination dots minimal and subtle.

3️⃣ Account Creation
Screen: Choose Country
* Dropdown selector
* Clean typography
* Minimal flag icon (small, subtle)
Screen: Phone Number Entry
* Country code auto-filled
* Large numeric input
* Primary CTA: Continue
Screen: OTP Verification
* 6-digit input
* Auto-focus animation
* Calm confirmation checkmark

🔐 IDENTITY VERIFICATION (KYC FLOW)
Make this feel secure but not stressful.

4️⃣ Identity Intro Screen
Headline: “Let’s verify your identity.”
Subtext: “For your security and compliance.”
Simple 3-step indicator:
1. Portrait
2. Valid ID
3. Review

5️⃣ Live Portrait Capture
* Camera interface with blurred background
* Soft facial outline guide
* Instruction: “Align your face within the frame.”
* Subtle glow when properly aligned
* Auto-capture
* Soft green confirmation

6️⃣ ID Capture (Front & Back)
* Rectangle detection overlay
* Instruction: “Place your valid ID inside the frame.”
* Capture front
* Capture back
* Auto-edge detection animation
Progress indicator remains visible at top.

7️⃣ Verification Processing Screen
* Minimal loading animation (thin rotating line)
* Message: “Verifying your identity”
* Reassuring subtext: “This usually takes less than a minute.”

8️⃣ Verification Success Screen
Large checkmark icon (soft green)
Headline: “You’re verified.”
CTA: Continue to Setup

🧠 PERSONALIZED FINANCIAL SETUP FLOW
This makes the app feel intelligent from day one.

9️⃣ Financial Intent Screen
Question: “What would you like to focus on?”
Selectable cards:
* Send money home
* Build savings
* Improve credit
* Manage expenses
Multiple selection allowed.

🔟 Set First Goal (Optional but Encouraged)
* Input goal name
* Target amount
* Target date
* Option toggle: Individual / Group
Subtle preview of circular progress component.

1️⃣1️⃣ Enable Credit (Optional)
Headline: “Unlock your credit line.”
* Short explanation
* Credit limit preview
* Accept terms checkbox
* Soft primary CTA
Make this transparent and responsible.

1️⃣2️⃣ AI Assistant Introduction
Chat-style intro message:
“Hi, I’ll help you reach your goals faster.”
Quick suggestion chips:
* Analyze my budget
* Plan my savings
* When can I send money home?
Subtle animated typing dots.

1️⃣3️⃣ Home Dashboard (First Arrival State)
Show:
* Wallet Balance
* Available Credit
* First Goal Card
* AI Insight Card
* Upcoming Calendar Item
Everything should feel: Organized. Calm. Empowering.

🎨 Visual System Rules
* Warm white background
* Deep navy primary
* Indigo/violet gradient accents
* 16–24px corner radius
* Thin stroke icons
* Clean card elevation
* Large breathing spaces
* No clutter
* No gamified confetti
* Soft micro-animations only

💫 Emotional Objective
From signup to dashboard, the user should feel:
Safe. Recognized. Empowered. Guided. Financially intelligent.
The onboarding should feel like a premium digital bank — not a crowded fintech app.
